# 研究計画書：身体シミュレーションを通じた描画運動の獲得と階層的シンボルの自己組織化

## 1. 研究の背景と目的

人間の子供は、身体（腕）の物理的・解剖学的特性に依存した「殴り描き」からスタートし、徐々に「丸」や「直線」といった描画プリミティブを獲得し、最終的には「顔」などの意味的シンボルを描く能力を獲得する。

本研究の目的は、4自由度ロボットアームの物理シミュレーションとニューラルネットワークを用い、**「将来予測の効率化（空間・時間の二重圧縮）」を内発的動機として、連続的な運動制御から離散的なシンボルがボトムアップかつ動的に自己組織化する発達プロセス**を計算論的に再現・検証することである。

## 2. システム概要・モデル構成

世界モデル（物理環境）と、時間スケールの異なる二層構造の神経系モデル（視覚運動系＋記憶・高次思考系）により構成する。

* **外部環境（2D平面キャンバス）**
	* **入力**: 描画像 $I_t$（低次系へ入る）
	* **出力**: 関節トルク $u_t$（低次系から出力される）

* **低次：視覚運動系（Fast Clock / 毎ステップ 20ms）**
	* **内部処理**: 視覚Enc / 運動Enc $\rightarrow$ 低次元ボトルネック ($z_t$) $\rightarrow$ 運動Dec
	* **作用**: 外部環境との間で描画像 $I_t$ を受け取り、関節トルク $u_t$ を生成する。
	* **高次への出力**: 予測誤差（Surprise）/ イベント境界を高次系へ伝達する。

* **高次：記憶・高次思考系（Slow / Dynamic Clock / 可変時間チャンク）**
	* **入力**: 低次系からの予測誤差およびイベント境界
	* **内部機能**:
		* 動的に圧縮された潜在シーケンス $Z_k$ から未来の $Z_{k+1}$ を予測
		* 親のフィードバック（修正絵・シンボル）によるアライメント

### (1) 物理環境・身体モデル

* **世界**: 2D平面キャンバス＋ペン（固定1種類、消しゴムなし）。
* **身体**: 4自由度ロボットアーム（肩・肘・手首・手）。関節トルク入力により連続制御。
* **観測情報**: キャンバスのラスタ画像 $I_t$、アームの身体状態（位置・速度・加速度） $s_t$、描画オン/オフ状態。
* ※自身のアームの直接的な視覚情報は入力せず、描画痕跡（画像）のみを観測。

### (2) 神経系モデル構造

1. **視覚運動系（World Model / Fast Clock）**:
  * **動作頻度**: 毎ステップ（リアルタイム制御）。
  * **入力**: 描画像 $I_t$、身体状態 $s_t$、前回のトルク $u_{t-1}$。
  * **構成**: Enc-Dec構造の内部に極めて次元数の低い潜在空間 $z_t$（低次元空間ボトルネック）を配置。
  * **出力**: 関節トルク $u_t$、描画オン/オフ、予測される描画像 $\hat{I}_{t+1}$。

2. **記憶・高次思考系（Transformerベース自己回帰モデル / Dynamic Slow Clock）**:
  * **動作頻度**: イベント駆動（低次系の予測誤差に基づき可変）。
  * **構成**: 時間圧縮された高位潜在特徴の系列 $Z = (Z_1, Z_2, ..., Z_K)$ をトークンシーケンスとして処理。
  * **役割**: 過去の描画エピソードの記憶・想起、未来の $Z_{k+1}$ の予測（長期的な運動計画）を担当

## 3. 運動計画とシンボル自己組織化のメカニズム

複雑なCodebook（VQ）等の固定モジュールを排除し、**空間・時間方向のボトルネック**と**情報ボトルネック（Information Bottleneck: IB）型損失関数**の組み合わせにより、シンボルと運動チャンクを自律形成させる。

### (1) 目的関数（IB型 Loss）

$$\mathcal{L} = \mathcal{L}_{\text{predict}} + \beta \cdot \mathcal{L}_{\text{compress}}$$

* **$\mathcal{L}_{\text{predict}}$（将来予測損失）**: 潜在状態と過去の履歴から、未来の感覚・描画状態 $\hat{I}$ および身体状態をどれだけ正確に予測できたか（MSE / 予測誤差）。
* **$\mathcal{L}_{\text{compress}}$（情報圧縮損失）**: 潜在空間の情報量を正則化（事前分布とのKLダイバージェンス等）。

### (2) 空間・時間方向の二重ボトルネック

* **空間ボトルネック（低次元化）**:
アームの慣性・可動域の制約（身体性）と空間圧縮により、無駄な揺れやノイズが削ぎ落とされ、頻出する軌道（円、直線等）が $z_t$ 空間上の特定の領域へ自然にクラスタ化（空間的シンボル創発）する。
* **時間ボトルネック（動的チャンキング / Dynamic Time-Chunking）**:
低次 World Model の「予測誤差（Surprise）」の急増点をイベント境界として自動検出する。
* **未習熟・精密な描画**: 予測誤差が大きく跳ね上がるため、高次系が密に介入（短いチャンク / Fast Clock寄り）。
* **熟練・定型運動**: 予測が安定するため、高次系は長尺の指示 $Z_k$ を維持（長いチャンク / Slow Clock）。
* **結果**: 「慣れた基本軌道は1つの運動チャンクとして一気に描き、未習熟な動作や精密な修正運動では細かく意識を介在させる」という発達的変化が自然発生する。

### (3) 能動的推論（Active Inference）による運動計画と自己修正

* **目標想起**: 親からの提示絵やシンボル刺激を受けた際、高次系が対応する目標潜在系列 $\hat{Z}_{\text{target}}$ を想起。
* **潜在空間での計画**: 想起した $\hat{Z}_{\text{target}}$ と現在の潜在状態の差分（予測誤差）を最小化するように、World Model上で運動軌道（トルク列）を逆伝播・生成。
* **自己修正**: 描画実行中、リアルタイムのキャンバス画像から得られる潜在状態と目標 $\hat{Z}_{\text{target}}$ のズレを検知し、予測誤差（Surprise）をトリガーに高次系が介入して軌道を微修正する。

## 4. シミュレーション・学習の流れ

1エピソード＝白紙からスタートする固定時間の描画過程。

| ステップ | 処理内容 |
  |
| **1. 観測 & 低次制御** | キャンバス画像 $I_t$ と身体状態 $s_t$ を観測。視覚運動系で低次元表現 $z_t$ へ圧縮し、トルク $u_t$ を出力してアームを駆動。 |
| **2. イベント検知（時間圧縮）** | 低次系の予測誤差（Surprise）を評価。閾値を超えた場合（または状態の節目）のみ高次系へシグナルを送り、そこまでの系列を1つのチャンク $Z_k$ として符号化。 |
| **3. 高次記憶の更新・計画** | 高次系（Transformer）が $Z_k$ を受け取り、長期的な描画文法として記憶・更新し、次の高位意図 $Z_{k+1}$ を予測。 |
| **4. エピソード終了（親の介入）** | 親による「修正された絵」および「他者（模範）の絵」「シンボル教師」が提示される。 |
| **5. パラメータ更新** | 自己の描画結果と親の提示結果との差分（対照学習損失等）＋ IB型Lossを用いて、全系のパラメータを更新。 |

## 5. 発達段階の検証シナリオ

学習の進展に伴い、システムが以下の発達フェーズを順次辿るかを検証する。

1. **フェーズ1（殴り描き・密な制御）**: 身体ダイナミクスに依存した無秩序な線。全域で予測誤差が高いため、時間圧縮は「密」であり、高次系が常に細かく介入。
2. **フェーズ2（描画プリミティブと運動チャンクの創発）**: 低次元潜在空間上に「丸」「直線」の空間クラスタが形成され、同時にそれらが1つの運動チャンク（疎な時間圧縮）として高速に実行可能になる。
3. **フェーズ3（階層的シンボルの構成）**: 高次系が長尺なチャンク系列（例：「輪郭の丸」＋「目の点2つ」＝「顔」）の文法的組み合わせを獲得。
4. **フェーズ4（動的自己修正・目標描画）**: 提示された目標シンボルに対して潜在空間上で運動計画を立て、定型部分は「疎（高速）」に描き、微修正が必要な部分は自動的に「密（慎重）」へ切り替えて描画を完了させる。

## 6. 本研究の意義と新規性

* **身体性と記号の接続**: 4自由度アームの動力学（関節トルク・慣性）を起点とすることで、「なぜ特定の図形から発達するのか」を解剖学的・運動学的な制約から論理的に説明可能。
* **空間・時間の二重ボトルネックによるミニマルな実装**: 複雑なVQモジュールや手動のルール定義に頼らず、「低次元化＋動的時間圧縮＋将来予測」という最小限の原理から、空間的シンボルと時間的運動チャンクの双方が自律的に立ち現れることを証明する。
